# إعداد app-ads.txt لشجيرتي

لا يُنشر ملف `app-ads.txt` في النسخة الحالية لأن سجل الناشر الرسمي لم يُعتمد بعد. هذا يمنع نشر ملف فارغ أو سجل غير صحيح باسم شجيرتي.

## قبل النشر

1. افتح حساب Google AdMob الخاص بمالك شجيرتي.
2. انسخ **السطر الرسمي الكامل** الذي تعرضه AdMob لإعداد `app-ads.txt`.
3. أنشئ `public/app-ads.txt` وضع فيه السطر الرسمي فقط، من دون قيم تجريبية أو تعليقات بديلة.
4. لا تستخدم Android App ID ولا Banner Ad Unit ID؛ فهما ليسا سجل `app-ads.txt`.
5. انشر الموقع على الدومين المسجّل في صفحة التطبيق بالمتجر وAdMob.
6. افتح الرابط مباشرة وتأكد أنه يعرض نصًا عاديًا بلا HTML أو تحويل.
7. اطلب من AdMob إعادة التحقق وانتظر تحديث حالة الزحف.

## اختبار محلي

بعد إضافة السجل الرسمي وتشغيل `npm run build` يجب أن يوجد الملف:

`out/app-ads.txt`

ويتحقق منه الفاحص الآلي عبر:

`npm run validate`

الفاحص يسمح بعدم وجود الملف قبل الاعتماد، لكنه يرفض نشر ملف فارغ أو وضع App ID أو Ad Unit ID داخله. لا يستطيع الفاحص التحقق من ملكية سجل الناشر؛ مصدر الحقيقة الوحيد هو حساب AdMob الخاص بالمالك.
