# تقرير تطوير الصفحة الرئيسية ودليل أشجار شجيرتي

تاريخ المراجعة: 18 أكتوبر 2026
الحالة: منجز محليًا — لم يتم النشر

## الملخص التنفيذي

طُوّرت الصفحة الرئيسية الحالية لتصبح تجربة تحريرية وتعليمية وتسويقية متكاملة، مع إضافة دليل أشجار محلي قابل للبحث والتصفية وصفحات ثابتة لكل نوع. حافظ التنفيذ على هوية شجيرتي الخضراء والبيج، وعلى جميع الصفحات القانونية ومساراتها، ولم يلمس تطبيق Flutter أو Supabase.

## الأقسام المنفذة

1. Hero بصورة طبيعية ولقطة فعلية من التطبيق وزري اكتشاف الأشجار والتحميل.
2. مقدمة تحريرية عن القيمة البيئية للأشجار واختيار النوع المناسب.
3. قسم «أشجار تنمو في أرضنا» بستة أنواع موثقة في السعودية.
4. مسار أفقي لأشجار الزينة مع تمييزها صراحةً عن الأنواع المحلية.
5. استكشاف حسب الفئة: النخيل، الصحراوية، الظل، الزينة، المثمرة، والمحلية.
6. مستكشف الخليج باختيار يدوي للسعودية والإمارات والكويت وقطر والبحرين وعُمان.
7. «شجرة مميزة» بدل ادعاء تحديث أسبوعي غير موجود.
8. شرح بصري لعلامات التعرف: الورقة والجذع والثمرة والزهرة والتاج والسياق.
9. رحلة تطبيق شجيرتي بأربع خطوات ولقطات حقيقية من التطبيق.
10. دليل عناية عام لا يقدم جدول ري ثابتًا لكل الأنواع.
11. معلومات نباتية سريعة بتخطيط Bento تحريري.
12. مقارنة نخيل التمر بواشنطونيا مع تنبيه لحدود التعرف البصري.
13. قسم «لماذا شجيرتي؟» دون أرقام مستخدمين أو تقييمات مختلقة.
14. أسئلة شائعة موسعة حول الدقة والنخيل والسعودية والإنترنت والأسعار والتوفر.
15. دعوة ختامية للتحميل تعرض «قريبًا» ما دام رابط Google Play الرسمي غير متوفر.
16. Footer محفوظ بجميع الصفحات القانونية مع إضافة «من نحن» و«دليل الأشجار».

## الصور والتراخيص

- أضيفت 12 صورة حقيقية مرتبطة مباشرةً بالأنواع من Wikimedia Commons.
- حُوّلت الصور إلى WebP بعرض أقصى 1500 بكسل وجودة 82 لتقليل الحجم مع الحفاظ على التفاصيل.
- يظهر مصدر الصورة والمصور والترخيص في صفحة كل نوع.
- التراخيص المستخدمة: CC BY، CC BY-SA، والملكية العامة حسب الملف الأصلي.
- لا توجد صورة مخزنية عامة مستخدمة لتمثيل نوع مختلف.

## تحسينات التصميم والتفاعل

- تخطيط Editorial متنوع بدل تكرار شبكة بطاقات واحدة.
- Hero بصري، أقسام فاتحة وداكنة، صور عريضة، قوائم تحريرية، Carousel أفقي، Bento، ومقارنة بصرية.
- البحث يعمل بالاسم العربي أو العلمي.
- تصفية حقيقية حسب الفئة، وروابط الفئات تفتح الدليل مع الفلتر المطلوب.
- اختيار دولة الخليج يدوي ولا يطلب الموقع الجغرافي.
- التصميم Mobile First مع نقاط كسر عند 960 و700 و460 بكسل، ومنع overflow الأفقي على مستوى الصفحة.
- احترام `prefers-reduced-motion` للحركات الحالية.

## SEO والأداء

- Metadata عربية لدليل الأشجار وصفحات الأنواع.
- إضافة كلمات مستهدفة: أشجار السعودية، أشجار الخليج، أنواع النخيل، والأشجار الصحراوية.
- تحديث Sitemap لتضمين دليل الأشجار وصفحات الأنواع الاثنتي عشرة.
- صفحات الأنواع Static Generation عبر `generateStaticParams`.
- بيانات منظمة محافظة من نوع `WebPage` مع روابط `citation`؛ لم يستخدم Schema غير موجود أو مضلل باسم Plant.
- الصور المحلية عبر `next/image` وWebP، ولا توجد مكتبة Animation إضافية.
- الصفحة تعتمد Server Components، مع JavaScript عميل محدود للبحث والتصفية وتبديل الدولة.

## نتائج الاختبارات

- `npm run lint`: ناجح، دون تحذيرات.
- `npm run typecheck -- --incremental false`: ناجح.
- `npm run build`: ناجح.
- Next.js ولّد 35 صفحة ثابتة، تشمل 12 صفحة نوع عبر SSG.
- `npm run validate`: ناجح.
- المدقق تحقق من 30 مسارًا، منها 12 صفحة نوع، ومن الروابط المحلية وSEO وSitemap وملفات الجذر القانونية والإعلانية.
- فحص HTTP محلي: الصفحة الرئيسية، دليل الأشجار، صفحة الغاف، وسياسة الخصوصية أعادت 200.
- تعذّر الفحص البصري الآلي داخل متصفح Codex لأن سياسة أداة المتصفح حجبت الوصول إلى عنوان loopback المحلي. لم يُعتبر ذلك نجاحًا بصريًا وهميًا؛ المعاينة المحلية باقية على `http://127.0.0.1:3000/` للمراجعة اليدوية على الكمبيوتر والجوال.

## ما يحتاج مراجعة قبل النشر

1. مراجعة بصرية نهائية على هاتف فعلي وعلى عرض Desktop، خاصة طول الصفحة وحجم النص في أقسام المقارنة والدليل.
2. اعتماد النصوص التحريرية والمصطلحات العربية المحلية.
3. مراجعة قانونية لتراخيص الصور وطريقة الإسناد قبل النشر العام.
4. إضافة رابط Google Play الحقيقي فقط بعد نشر التطبيق واعتماد الرابط.
5. تحديد الدومين الرسمي والبريد والمالك القانوني في متغيرات البيئة.
6. توسيع قائمة الأشجار لاحقًا فقط بعد مراجعة علمية مماثلة؛ لم تُنشأ صفحات مكررة أو فارغة.

## قرار النشر

لم يُنشر الموقع التزامًا بطلب المستخدم. النسخة الحالية محلية وجاهزة للمراجعة.
